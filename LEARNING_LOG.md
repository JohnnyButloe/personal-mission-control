## Phase 1 — Issue 1: Initialize Next.js Application

### What I learned

- Next.js is built on React and provides routing, rendering, build tooling, and application structure.
- The App Router uses the `src/app` directory to define routes.
- `layout.tsx` provides shared UI around pages.
- `page.tsx` represents the UI for a route.
- `package.json` defines dependencies and npm scripts.
- TypeScript provides static type checking.
- ESLint checks code for common problems and coding-rule violations.
- Tailwind provides utility classes for styling.
- `npm run dev` starts the local development environment.
- `npm run build` creates and validates the production build.

### Things I want to reinforce

- Server Components vs. Client Components
- Nested App Router routes
- How layouts work across routes
- How Tailwind is processed
